# Experiment run data

- BASS-II (`bass-bass-ii-bass-m.json`): NASA/TM-20210011385 (NTRS 20210011385), Table 5.1 (20 PMMA slab tests, ambient pressure unprinted -> `pressure_atm: null`), and Table 7.1 (27 SIBAL fabric tests). The four original BASS runs at the bottom of Table 7.1 are excluded.
- Saffire I–III (`saffire-i-iii.json`): NASA NTRS 20180005168, Table 1 and its continuation (slides/PDF pp. 30–31: 2 Saffire I burns, 9 Saffire II samples, 2 Saffire III burns; ambient pressure unprinted -> `pressure_atm: null`). NASA NTRS 20180004258, slide 18, corroborates selected qualitative results.
- FLEX-1 (`flex-1.json`): NASA/TP-2015-216046 (NTRS 20150023456), Table IX, pp. 20–28 (PDF pp. 26–34), 276 isolated methanol and n-heptane droplet tests (`FLEX-001` through `FLEX-280`, omitting numbers `156`, `205`, `213`, `228` absent from Table IX) across N2, CO2, and He diluents and ambient pressures 527.6–2319.9 mmHg (`pressure_atm` computed as `mmHg / 760`, `0` cm/s quiescent airflow). For isolated droplets, `spread_rate_mm_s` records the published burning rate constant $K$ ($\text{mm}^2/\text{s}$) and `thickness_mm` records the initial droplet diameter $d_0$ (mm); missing `"–"` cells remain `null`.
- SoFIE-MIST & ACME-BRE: No per-run tabular files are included until raw NASA PSI CSV/PDF tables are ingested; study-level cards link to NASA's primary pages (`science.nasa.gov/biological-physical/investigations/sofie-mist/` and `science.nasa.gov/physical-sciences-informatics-psi/nasa-psi-research-opportunity/`).

Geometry follows the primary row or the associated setup section. Missing numeric values remain `null`. Files are loaded by the NASA KB importer using existing study slugs. Each row carries a verified source citation and locator. These records describe flight tests in microgravity; they do not provide measured lunar or Martian fire thresholds.
